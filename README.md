# 🐍 Projetos Python

Este repositório reúne projetos desenvolvidos durante minha jornada de aprendizado em Python, com o objetivo de praticar lógica de programação, estruturas de dados, funções e manipulação de arquivos.

## 📚 Projetos

### 1. Gerenciador de Tarefas

Sistema para organizar tarefas do dia a dia.

**Funcionalidades:**
- Cadastrar tarefas.
- Listar tarefas.
- Pesquisar tarefas.
- Marcar tarefas como concluídas.
- Excluir tarefas.
- Salvar informações em arquivo JSON.

### 2. Sistema de Estoque

Sistema para gerenciar produtos e controlar quantidades em estoque.

**Funcionalidades:**
- Cadastrar produtos.
- Listar produtos.
- Pesquisar produtos.
- Atualizar informações.
- Excluir produtos.
- Controlar preços e quantidades.
- Armazenar dados em arquivo JSON.
